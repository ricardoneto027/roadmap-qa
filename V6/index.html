Portfolio GitHub — O que construir e como
Regra de ouro: Empregadores em Portugal verificam o GitHub antes da entrevista. Não precisas de muito — precisas de repositórios limpos, com bom README, que mostrem que sabes fazer o trabalho real. Qualidade > Quantidade.

qa-portfolio

    CI/CD — Ferramentas e Certificações
    O que é CI/CD para QA: Integrar os teus testes automáticos numa pipeline — quando um developer faz push de código, os testes correm automaticamente. Não constróis a pipeline do zero (isso é DevOps), mas tens de saber configurar a parte dos testes e interpretar resultados. As vagas que partilhaste pedem Azure DevOps, GitLab, Jenkins e Bitbucket.
