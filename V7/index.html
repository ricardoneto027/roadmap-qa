Como maximizar este sprint
Trata-o como entrega real para um cliente
README com: contexto do projecto, o que foi testado, ferramentas, como correr os testes automáticos, métricas (X test cases, Y bugs, Z automatizados) · Escreve como se fosse um relatório para o teu manager
Publica tudo no GitHub antes da avaliação
Repositório organizado: /manual-tests, /automation, /bug-reports, /docs · Screenshots de bugs · Postman collection exportada · Código Selenium com POM · Este é o repositório que vais mostrar em entrevistas
Prepara o "projecto pitch" de 2 minutos
Consegues explicar: o que testaste, que técnicas usaste, um bug interessante que encontraste, uma decisão que tomaste? · Entrevistas técnicas pedem exactamente isto · Pratica em voz alta antes da aprovação
